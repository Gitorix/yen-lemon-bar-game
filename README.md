# 100円レモン

Discordの画面共有で資料と一緒に見せられる、配信用の高難度ブラウザゲームです。実際のワイングラスに浮くレモンの写真を舞台に、動く安全エリアを狙って100円玉を落とし、3秒間バランスを保ちます。3枚成功でラウンドクリアです。

## 起動方法

公開版: https://gitorix.github.io/yen-lemon-bar-game/

GitHub Actionsはセキュリティ検査後に`node scripts/build.mjs`で公開用ファイルを生成します。
公開するファイルは明示的な許可リストに限定し、APIキーや設定ファイルを配信しません。
詳しい運用方法と制限は[SECURITY.md](SECURITY.md)を参照してください。

依存パッケージはありません。ブラウザが使える環境で、プロジェクトのフォルダから次のコマンドを実行してください。

```bash
python3 -m http.server 5173
```

ブラウザで [http://localhost:5173](http://localhost:5173) を開きます。`index.html` を直接開いても表示できますが、ローカルサーバー経由の方が安定します。

## 主要操作

- ゲーム画面をクリック / タップ：その位置へ真上から100円玉を投入
- 「狙い目」：レモンの揺れ幅を2秒間半減（2回まで）
- 音ボタン：効果音のON / OFF
- `RESET`：記録・積み上げ・スキルを初期化

安全エリアは常に薄く表示され、時間と成功枚数に応じて小さくなりながら不規則に移動します。スキル使用中は輪郭とラベルが強調されます。積むほど重心・傾き・着地時の揺れの影響が強くなります。

## Discord配信での使い方

1. ブラウザでゲームを開きます。
2. ブラウザのウィンドウを表示したい大きさに調整します。
3. Discordでブラウザのウィンドウ、または画面全体を共有します。
4. 資料をメインに表示し、ゲーム窓を右下へ配置します。

ゲームの画面自体が小さくなっても、現在の状態・バランス・投入ガイドが見えるようにレイアウトを調整しています。スマホではタップ操作と縦長レイアウトに自動対応します。

## 実装メモ

- Canvas 2Dで透明グラス、水面の反射・泡・揺らぎ、コイン、ターゲット、粒子演出を描画
- レモンはプロジェクト内の生成・背景除去済み写真素材 `assets/lemon-real.png` を使用し、読み込み前はCanvas描画へフォールバック
- クリック位置、レモンの傾き、既存コインの重心、積み上げ枚数を使ってバランスを評価
- 提供されたワイングラスと浮遊レモンの写真をCanvas背景として使用
- 受け面を狭く設定し、3枚目に向けて安全エリアの幅と安定度が下がる高難度調整
- 100円玉は銀色の縁刻み、「100」「日本国」、桜枝風のモチーフをCanvasで描画
- 着地後3秒のカウントダウン中に揺れが大きくなると「惜しい」演出から落下・没収
- Web Audio APIの短い効果音をコード生成。音声ファイルや外部ゲームエンジンは不要
- 外部JavaScript・フォント・API依存なし。フォントはシステムフォントを使用
